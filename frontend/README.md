# RIVR frontend

React + TypeScript + Vite. See the [root setup guide](../README.md) for Docker and native workflows, API proxy configuration, and team conventions.

```bash
npm ci
npm run dev
npm run build
npm run lint
npm test
npm run test:coverage
```

Vitest, jsdom, and Testing Library are configured. Feature tests will be added with the table UI; test commands currently report no tests. The visible app is still the original Vite starter.
