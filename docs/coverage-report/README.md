## What is measured

- **Backend:** `accounts`, `core`, `friends`, `profiles`, `tables` (`backend/.coveragerc`). These are all of the project's Django apps. Excluded: `migrations/` (generated by Django), test files, and `config/` (settings and URL wiring, which every API test exercises anyway).
- **Frontend:** every `src/**/*.ts(x)` file (`frontend/vite.config.ts`). Excluded: `src/test/` (test setup) and `src/main.tsx` (the browser entry point). The `types.ts` files show 0% because they contain only TypeScript types, which produce no runtime code.

## Files

- `backend-coverage.txt`: per-file backend table with missing lines and branches.
- `backend-coverage.json`: full Coverage.py data, line by line.
- `frontend-coverage.txt`: per-file frontend table with uncovered lines.
- `frontend-coverage-summary.json`: Vitest's per-file summary.

## Reproduce

From the repository root, with Docker running:

```bash
docker compose up -d
docker compose exec backend pytest --cov --cov-report=term-missing
docker compose exec frontend npm run test:coverage
```

The numbers should match this report at commit `a24b9c7`. After later changes, re-run the commands and update this folder.
