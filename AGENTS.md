# RIVR repository guidance

Read `instructions.md` for setup and Git workflow, and `docs/contracts.md` for shared interfaces. Reusable role briefs live in `.agents/`; see `.agents/README.md` for selection and usage.

When a teammate selects a role, read `.agents/shared.md` and that role's file. Do not load every role or start multiple agents automatically. If no role is selected, use the task's story IDs to identify the relevant brief. Preserve the user's requested scope and human story ownership.

These Markdown briefs provide repository instructions. They do not register native subagent types, launch background agents, or authorize commits, pushes, or merges by themselves.
